# Starred Randomizer

Explore GitHub starred repositories and keep a personal selection of favorites.

## Language

**Application user**:
A registered user of Starred Randomizer who owns a personal collection of favorites. An application user is distinct from the GitHub user whose starred repositories are being explored.
_Avoid_: GitHub account, when referring to the application identity

**GitHub API token**:
A personal access credential optionally supplied by an application user to authorize requests to GitHub. It is not a method for signing in to Starred Randomizer.
_Avoid_: Login token, session

**Favorite**:
A repository explicitly saved in a personal selection inside Starred Randomizer. A favorite is distinct from a repository starred on GitHub.
_Avoid_: Star
